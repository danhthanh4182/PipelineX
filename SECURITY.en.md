# Security Policy

If you discover an authorization bypass, credential exposure, injection vulnerability, or other security issues impacting deployment safety, please contact the maintainers via [GitHub Private Vulnerability Reporting](https://github.com/KKKKhazix/AIHOT/security/advisories/new).

Please provide:
- Affected commit hash, deployment method, and essential environment details.
- Minimal reproduction steps executed in an authorized test environment.
- Potential impact and sanitized log excerpts or screenshots.

Please do NOT publicly disclose exploitable vulnerabilities in public Issues, Discussions, or PRs. Never upload production API keys, credentials, cookies, or real database dumps. For standard usage inquiries and non-security bugs, please use [GitHub Discussions](https://github.com/KKKKhazix/AIHOT/discussions) or [Issues](https://github.com/KKKKhazix/AIHOT/issues).
